# 期租是更好的盈利锚点，但究竟锁定了什么？

**研究日期：2026年10月12日**

[English](charter_anchor_en) | [DHT Q4](report_cn) | [FRO 历史 PE](fro_2007_2009_cn) | [首页](../)

> **结论：** 应用公司实际合同及剩余期租天数锚定前瞻盈利，而不是将现货尖峰永久资本化。但期租锁定的是**租金条款**，不是无条件净利润。Fearnleys 第41周原始 PDF 列示：**10月7日现代节能／脱硫塔 VLCC 的1年期租评估为 $230,000/天，周涨 $45,000**。这支持用户讨论的 $250,000/天量级，但它**不是具名已签成交**。DHT Panther 的 **$100,000/天、3年**则是公司披露的合同。
>
> 按下文明确成本假设，**$250,000/天、365个付租日**对应 **$91.25m 毛租金和 $78.96m 示意利润**；若为 **350个付租日**，利润是 **$75.26m**。约 $80m 的直觉在算术上合理，但不能说这笔净利润已无条件锁定在下一日历年的报表中。

所有租金均为**美元／天**，租期另列。“$250k／1年”（25万美元／天、1年）不表示全年总租金 $250k。`m` 表示百万美元。本文是专题研究扩展，不是新的全公司估值或经过校准的交易规则。

## 1. 静态与动态 PE：先定义分母

“动态 PE”在不同数据供应商处并不是同一个标准字段，可能指累计／季度盈利年化，也可能指预测全年盈利。必须先看供应商定义。

| 指标 | 本文定义 | 主要风险 |
|---|---|---|
| 静态 PE | 股价 / 最近披露的完整年度 EPS | 上年盈利可能过时 |
| TTM PE | 股价 / 滚动盈利 | 高利润季度移出缓慢；存在公告滞后 |
| 单季年化 PE | 股价 /（最近已披露季度 EPS × 4） | 将季节性和一次性项目年化 |
| 预测财年 PE | 股价 / 明确预测的财年 EPS | 是预测，不是实际值；剩余日历月份有影响 |
| 未来12个月 PE | 股价 / 真正未来12个月的预计盈利 | 需要合同清单、未覆盖天数假设和公司全部成本 |

为与前篇保持可比，继续使用其中的 **10月12日参考股价 $26.22**，不宣称它是最新实时价格：

| DHT 盈利分母 | 近似倍数 | 证据状态 |
|---|---:|---|
| FY2025 EPS $1.31 | 20.02x | 静态，已报告年度 EPS |
| 截至 Q2 2026 最近四个已报告季度 | 8.92x | 已报告利润的 TTM 近似 |
| 最近已报告 Q2 2026 EPS $1.23 × 4 | 5.33x | 已报告季度年化，不是前瞻预测 |
| 假设 Q4 利润 $520m × 4 | 2.03x | 年化情景，不是已赚到 |
| 纳入该 $520m Q4 的 FY2026 情景 | 3.68x | 前篇示意模型，包括已说明的一次性收益 |
| 实际未来12个月、以合同支持的公司盈利 | 未知 | 尚未完成全部合同和成本重建 |

**20x 静态和 2x 单季年化可以同时算对，却不证明存在十倍估值机会。** 改变的是分母。前篇 Q4 假设及限制在[计算说明](report_cn)中保持不变。

### 历史检验：FRO 也存在相同区别

使用前篇**原始每股价格**与财报滞后近似。此处静态 PE 使用最近上年完整业绩，**不是前篇的“当年最终全年盈利”列**。动态列年化的是前一份已披露季度，而非当前尚未公布的季度。本表保留前篇的取整、重述和公告版本限制，不是精确时点回测。

| 季末 | 静态 PE | 近似已披露窗口 TTM PE | 最近季度年化 PE |
|---|---:|---:|---:|
| 2007Q1 | 5.14x | 5.14x | 4.93x |
| 2007Q2 | 6.64x | 7.44x | 5.41x |
| 2007Q3 | 7.00x | 6.21x | 4.77x |
| 2007Q4 | 6.96x | 7.09x | 37.50x |
| 2008Q1 | 5.99x | 5.99x | 4.26x |
| 2008Q2 | 9.16x | 8.26x | 5.91x |
| 2008Q3 | 6.31x | 4.71x | 2.83x |
| 2008Q4 | 3.89x | 2.64x | 5.33x |
| 2009Q1 | 1.90x | 1.90x | 6.59x |
| 2009Q2 | 2.66x | 3.39x | 6.21x |

**2008Q3末**，将很强的 Q2 年化会让股票看起来只有 **2.83x**，此时股价高点已经过去。到 **2009Q1末**，静态／TTM **1.90x** 与最近季度年化 **6.59x** 并存：最近盈利已经明显弱于旧年度分母。

但 **2007Q4 的 37.50x** 单季年化读数之后，又出现了强劲的2008年市场。这个比较可以诊断盈利构成／动能，不能证明巨大差距能够预测股价下跌。

在统一股数口径下：

```text
TTM PE / 单季年化 PE
  = 最近季度年化 EPS / TTM EPS
```

股价被约掉。这是盈利比率恒等式，**不是独立估值信号**。FRO 在2008Q3的该比率为 **1.67**，部分受 Q2 收益项目支撑；2009Q1为 **0.29**。在将其解释为经营动能之前，应先剔除一次性项目。

## 4. $250,000/天是否锁定约 $80m 净利润？

### 收入算术很清楚

```text
$250,000/天 × 365个付租日 = $91.25m 毛租金
$230,000/天 × 365个付租日 = $83.95m 毛租金
$100,000/天 × 365个付租日 = $36.50m 毛租金
```

常规期租通常由租家承担普通航次成本，船东仍承担技术营运费用、折旧和融资。实际战争险、停租、制裁及航区条款必须看合同；期租不是光船租赁。

### 自有单船利润桥接示例

以下均为**假设**，不是 DHT／FRO 单船披露：

| 项目 | 假设 |
|---|---:|
| 佣金 | 毛租金的 1.25% |
| 营运费用 | 每个日历日 $10,000 |
| 承担船东费用的日历天数 | 365 |
| 年折旧／假设包含的坞修摊销 | $5.00m |
| 年利息 | $2.00m |
| 分摊管理费 | $0.50m |
| 所得税 | 假设 $0，不是税务判断 |

模型停租日仍承担船东成本。贷款本金和资本开支**不在这个净利润桥接中再次费用化**，其现金流影响应另外建模；不能将维修资本开支及其摊销扣两遍。

| 日租金 | 付租天数 | 毛租金 | 扣模型费用后的示意利润 |
|---|---:|---:|---:|
| $100,000 | 365 | $36.50m | $24.89m |
| $100,000 | 350 | $35.00m | $23.41m |
| $230,000 | 365 | $83.95m | $71.75m |
| $230,000 | 350 | $80.50m | $68.34m |
| $250,000 | 365 | $91.25m | $78.96m |
| $250,000 | 350 | $87.50m | $75.26m |

所以，**完整租约年约 $80m 是合理量级，并非不可能**。在这些特定假设下，365个付租日要恰好赚 $80m，需要约 **$252,887/天**。更新／成本更高的船、融资变化、停租或不同佣金都会改变结果。

**被固定的是合同租金安排，并受履约和条款约束；净利润不是无条件保证。** 租家违约、解约争议、意外维修、未保险费用、减值和融资变化均会影响结果。

### 一个租约年不一定等于下一个财年

假设一份**示意**1年合同从2026年10月1日运行至2027年10月1日，日租金 $250,000、没有停租：

| 日历年 | 付租天数 | 毛租金 |
|---|---:|---:|
| 2026 | 92 | $23.00m |
| 2027 | 273 | $68.25m |
| 合同合计 | 365 | $91.25m |

单靠该合同，下一日历年报表**不会**收到完整的 $91.25m 收入或约 $80m 利润。到期后的盈利仍未锁定，除非另有合同。

$100,000/天、三个示意365天年份的毛租金合计是 **$109.50m**，尚未扣减费用和停租。它是更长的收入流，不是每年 $109.50m 利润；实际日历合同还可能包含闰日。

## 5. 比孤立 PE 线更好的候选指标

以下是**拟议诊断指标，不是已验证预测信号**。

| 指标 | 定义 | 用途／限制 |
|---|---|---|
| 未来12个月固定租金天数覆盖率 | 同窗口、同一可用天数集合内的确定固定价预计付租天数 / 该集合的全船队可用天数 | 分子分母一致剔除停租；浮动利润分享和未行权选项不算固定覆盖 |
| 已约净租金的现金费用覆盖率 | 扣佣金后的保底合同租金 / 同窗口全船队必要现金支出 | 看不确定现货收入之前，费用已覆盖多少；未覆盖船舶的成本也必须计入 |
| 到期与续租敞口 | 逐季到期天数，以及同口径续租费率相对到期旧租金的差额 | 识别被高滚动盈利掩盖的到期后盈利下降风险；股价可提前反应 |
| 合同支持的未来12个月 PE | 股价 / 固定净租金、明确未覆盖情景及全公司会计成本构成的预计 EPS | 更贴近未来经济性，但仍是模型，不是保证的 PE |
| 同口径期限结构 | 同日、可比船舶的1／2／3年报价和已完成成交 | 判断强势延伸到哪些期限；不是概率，也不能用不相关交易拼曲线 |

**现金费用覆盖率**的分母可以包括船舶营运、公司现金费用、现金利息、必要维修和计划还本；不要再加非现金折旧。计算**会计 EPS**则用折旧／利息，而不是贷款本金或资本开支。比较前必须先声明口径。

不可用／停租天数既不产生模型固定租金，也不产生假设现货收入，但适用的船东费用继续发生。覆盖率两边必须使用同一个可用天数集合，不能用合同日历天数除以更少的营运天数，制造超过全部利用率的覆盖。

前瞻 EPS：

```text
未来12个月盈利情景
  = 落在窗口内的合同净租金
  + 对未覆盖天数明确假设的净收入
  - 全公司营运、折旧、财务和税费
```

这里的**净收入**已扣航次费用及适用佣金，但**尚未扣除**船东营运、管理、折旧、利息和税费。必须核对具体 TCE 定义，不再重复扣除其中已经包含的航次费用或佣金。将归属普通股股东的模型利润除以**明确基本或稀释口径的预计加权平均股数，得到未来12个月 EPS**，再计算 **未来12个月 PE = 股价 / 该 EPS**；不能用每股价格除以公司总利润。

由于尚未重建完整前瞻合同清单、保底费率安排和公司成本，本文不发布全公司数字。若干具名合同不能悄悄代表整个船队，也不能当作已经认证的盈利下限。

### 一个重要的期限结构陷阱

仅对完全假设的**同船、同日、同条款**，作不折现比较：

```text
1年 $250,000/天，对比3年 $100,000/天
第2-3年剩余平均 = (3 × $100,000 − $250,000) / 2
                = $25,000/天
```

这只是算术示例，**不是从实际观察合同推出的远期费率**。不同交船日、信用、规格、航区灵活性、选项和折现会使简单计算失效。有价值的问题是，同口径更长期租金是否也在增强，而不是两个不相关费率能否算出吸引人的比值。

### 历史检验究竟确立了什么

静态／动态差额能够提示盈利过时或一次性项目扭曲，但两者比率中的股价会被约掉。2008年末的高价3年合同与股市下跌并存，它们不会自动保护未覆盖船队或剩余船舶价值。

真正的信号研究需要跨多个周期的时点合同清单、带日期可比报价和成交、全部成本及股东总回报，并对未覆盖敞口、到期集中度和续租做样本外检验。本次稀疏成交样本不足以确立最优阈值或信息领先。

## 6. 估值纪律

固定期租增强估值中的显性现金流部分，但不会使单年暴利永久化。先估计剩余合同现金流，再单独建模续租及资产剩余价值。

不能把全部期租利润流加到已包含附带合同经济性的船舶估值上。如果采用无租约船价，合同价值也不自动等于全部毛租金；还须比较替代营运、成本、时间和信用。

实际研究优先级是**真实保底费率覆盖及到期结构**，其次才是可比期租市场证据与扣成本的前瞻情景。静态、TTM和单季年化 PE 是交叉检查，不是多个独立投票。本扩展不验证或触发此前的分阶段退出模板。

**Day1Global／事前验尸：** 收入可见性只针对覆盖天数改善；会计利润不同于自由现金流；管理层增加覆盖会让出部分上行；单一租家可能造成信用集中。失败情景包括续租下降、意外停租、租家违约及资产剩余价值重估。概率、12／24个月目标价及全公司已验证利润下限仍为**未知**。

## 第二步——严格同行评审

### 1. 需要核实的事实

未确立 $250,000/天、1年期租的具名成交；经纪商观察来自归档评估。历史成交是选择性市场报道，2006年2年样本仍缺失。精确保底费率、可选租期、佣金分配及公司全部当前合同安排并不完整。

### 2. 逻辑跳跃／概念替换

动态 PE 依赖定义。评估不是签约，签约不是保证净利润，完整租约年不是下一日历年；多年平均租金不是每年最低保证。EPS 比率不提供独立价格信息。

### 3. 缺失的反例／竞争解释

固定船舶可以创造现金，同时未覆盖盈利和船价仍下跌。低单季年化 PE 可以由特定收益造成，高值之后也可能复苏。费率差可能来自船舶质量、合同灵活性和租家信用，而不只是预期。

### 4. 最重要的待补一手来源

完整租约经济条款或船东最低收入安排、实际起租／还船日、同规格时点经纪商曲线，以及单船／公司成本。这些是建立可靠公司前瞻 EPS 锚点的前提。

### 5. 推测而非事实

“下一年 $80m 已保证”“整个船队都能签 $230,000”“3年 $100,000 预测了第2-3年”“该 PE 差能预测顶部”均无足够支撑。利润和期限价差只是条件性示例。
